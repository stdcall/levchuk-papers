# В. М. Левчук. Сборник работ

Статьи В. М. Левчука и совместные работы об унитреугольных группах,
унипотентных подгруппах групп Шевалле и нильтреугольных алгебрах.

Статьи объединены по темам, внутри темы — по дате публикации.
Каждая статья сохраняет собственную нумерацию
результатов, формул и литературы. Пагинация сборника сквозная.

Русские публикации представлены в оригинале. Статьи, опубликованные
только по-английски, сохраняют английский текст. Переводы не образуют
повторных статей. Конференционные тезисы в сборник не включены.

Два близких изложения 2012 года сохранены вместе. Английская статья
подробнее доказывает многие результаты; русская содержит дополнительную
теорему о сопряжённости для F₄. Ссылки между статьями ведут
к соответствующим результатам.

`publications.bib` содержит отдельный библиографический каталог, включая
публикации, не вошедшие в сборник. Исходные списки литературы сохраняют
состав цитируемых авторами работ.

Обложку украшает векторный портрет по фотографии из
[профиля В. М. Левчука на портале «Ломоносов»](https://lomonosov-msu.ru/rus/user/profile/261918).

PDF сборника, вариант без редакционных примечаний и список исправлений
доступны в Releases. Правила сборки — в [CONTRIBUTING.md](CONTRIBUTING.md).
